## ⚡ Highlights & Key Features

- 🎯 **Authentic Visual Identity**: Dark-first Cyber Crimson & Obsidian HUD aesthetic matching photo lighting with subtle scanlines, dot-matrix patterns, and custom precision targeting cursor.
- ⚡ **Interactive Developer Terminal**: Live diagnostic commands (`whoami`, `metrics`, `stack`, `philosophy`, and quick command palette `Ctrl + K`).
- 🧠 **DSA Command Center**: 400+ LeetCode & 350+ Skillrack topic breakdown with interactive step-by-step **Binary Search Algorithm Visualizer**.
- 🚀 **Flagship Project — Memory Stack**: Detailed architecture breakdown of AI-powered spaced-repetition revision engine with modal case study dossier.
- ⚔️ **Hackathon War Room**: 24–48 hour rapid prototyping pipeline (Idea → Validate → Prototype → Build → Break & Debug → Ship).
- 🔬 **AI Lab Interactive Sandbox**: CLI simulator for local quantized LLMs (Ollama, Qwen2.5-Coder 7B, Gemini Flash fallback).
- 🎨 **Creative Studio & Photo Gallery**: DaVinci Resolve video editing showcase and full-resolution lightbox viewer for user photography and editorial posters.
- 🎛️ **Customization Tools**: Theme Accent Switcher (Crimson Red, Cyber Cyan, Matrix Emerald, Solar Amber, Neon Purple) and Web Audio API sci-fi sound effects toggle.
- 📱 **Fully Responsive**: Mobile-first responsive layouts tested across 375px, 768px, 1024px, 1440px+.

- **Deployment Ready**: Vercel / Netlify / GitHub Pages

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build

# 4. Preview production build
npm run preview
```
